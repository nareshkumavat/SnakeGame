# 🐍 Snake Game in Python  

This is a classic **Snake Game** built using Python and the Pygame library. It's a simple yet exciting project designed to strengthen programming fundamentals and learn game development concepts.  

---

## 🚀 Features  
- Move the snake using arrow keys.  
- Collect food to grow longer.  
- Avoid hitting the walls or yourself.  
- Real-time score tracking.  

---

## 🛠️ Technologies Used  
- **Python**  
- **Pygame Library**  

---

## 🖥️ How to Run the Game  
1. Clone this repository:  
   ```bash
   git clone https://github.com/<your-username>/Snake-Game-in-Python.git
2. Install the Pygame library if you don't have it already:
   ```bash
    pip install pygame

3. Run the game script:
   ```bash
    python snake_game.py
